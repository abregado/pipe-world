# Terrain Shader

The triplanar terrain shader that shades the ground and every cliff, and the scatter shader used for non-blocking clutter. Read this before changing terrain materials or the walkable-slope limit.

---

## Walkable Cue

[TriplanarTerrain.shader](../Assets/Shaders/TriplanarTerrain.shader) tells the player which surfaces can be walked on by switching texture with surface slope. A face whose world normal Y is above `_WalkableCos` shows the biome's bright **top** texture; anything steeper shows the darker **side** texture.

The threshold is [Walkable.SlopeLimitDegrees](../Assets/Scripts/Landscape/Biome.cs) (50°). The same constant sets the `CharacterController.slopeLimit` and each material's `_WalkableCos` (`Walkable.MinNormalY`), so what looks walkable is what is walkable. **Changing the limit means rerunning `WorldSetup` so both the player and the materials pick it up** (see [build-pipeline.md](build-pipeline.md)).

Because the mesh is flat-shaded, each face is classified whole, and the shader's [walkable factor](../Assets/Shaders/TriplanarTerrain.shader) (line 63) is a smoothstep of width `_EdgeSoftness` around the threshold.

Terrain, wall blocks and mesas all use the same three materials. A flat block top therefore uses exactly the same top texture, at the same world-space coordinates, as the terrain beside it.

---

## Projection

Everything is sampled in world space; the meshes have no UVs.

| Part | Projection |
|---|---|
| Top | World XZ, tile size `_TopScale` (14 m) |
| Side | Three-axis triplanar (X, Y, Z projections) weighted by `pow(abs(normal), 4)`, tile size `_SideScale` (10 m) |

### Hiding the tiling

A single repeating texture shows its repeat at distance. The top sample ([lines 68-76](../Assets/Shaders/TriplanarTerrain.shader)) therefore combines:

- The base sample.
- A second sample, rotated 37° and 1.9x larger, blended in by a much larger (7.3x) sample's brightness relative to the texture's average colour.
- A fine detail sample at 0.13x scale, applied as a small brightness change.

The texture's average colour comes from its lowest mip (`SAMPLE_TEXTURE2D_LOD` at level 12). **The macro and detail multipliers are clamped (0.75-1.25 and 0.88-1.12), because an unclamped multiplier can reach zero where a texture is darker than its average and renders as black.**

---

## Texture Fade

Past `_DetailFadeStart`, [the shader](../Assets/Shaders/TriplanarTerrain.shader) (line 98) blends the textured colour toward the texture's average colour, taken from its lowest mip. The walkable top and blocked side use separate averages, so far-away flat shading still separates walkable from blocked surfaces. See [visibility-and-depth.md](visibility-and-depth.md).

Fog is applied after lighting with `PW_ApplyFog`.

---

## Side Textures

Side textures are used on vertical faces, so they contain strata and streaks only. **Voronoi cells and crack lines belong on the top textures; on a vertical surface they read as tiling and are not used in `RockSide` or `IceSide`.** See [TerrainTextureGenerator.cs](../Assets/Editor/TerrainTextureGenerator.cs).

## Material Properties

| Property | Meaning |
|---|---|
| `_TopTex`, `_SideTex` | Walkable and cliff textures |
| `_TopTint`, `_SideTint` | Per-biome colour multipliers |
| `_TopScale`, `_SideScale` | Tile size in metres |
| `_WalkableCos` | Minimum normal Y that counts as walkable |
| `_EdgeSoftness` | Width of the top/side transition |
| `_BlockedDarken` | Brightness multiplier applied to non-walkable surfaces |
| `_AccentColor`, `_AccentStrength` | Tint applied to walkable surfaces |
| `_DetailFadeStart`, `_DetailFadeEnd` | Distances over which textures fade to flat colour |

Materials are generated by [WorldSetup.cs:137](../Assets/Editor/WorldSetup.cs) (`BuildTerrainMaterials`), one per biome, with textures from [TerrainTextureGenerator.cs](../Assets/Editor/TerrainTextureGenerator.cs). The generator writes 256 px tileable PNGs to `Assets/Art/Textures/Terrain/`, imported with sRGB on, mipmaps, repeat wrap and 8x anisotropic filtering.

## Lighting

Both shaders light through [PipeWorldLighting.hlsl](../Assets/Shaders/PipeWorldLighting.hlsl): flat ambient from the spherical-harmonics sample, plus the main directional light with its shadow attenuation and the additional (point) lights in the pixel's cluster; see [realtime-lights.md](realtime-lights.md). The sun is the only light that is always present.

[PipeWorldPasses.hlsl](../Assets/Shaders/PipeWorldPasses.hlsl) provides the `ShadowCaster` and `DepthOnly` pass functions. Each shader's passes include the same property header (`TerrainProps.hlsl`, `ScatterProps.hlsl`) so all passes share one `UnityPerMaterial` buffer and stay SRP Batcher compatible.

## Scatter Shader

[Scatter.shader](../Assets/Shaders/Scatter.shader) shades the clutter meshes. Colour comes from the vertex colour RGB (authored in sRGB, converted to linear in the shader). The vertex alpha is a glow mask: `lit += albedo * _GlowTint * alpha * _EmissionStrength`. Only the crystal tips and torch flames write a non-zero alpha. **The glow is added after fog**, so glowing vertices stay visible at any distance; see [visibility-and-depth.md](visibility-and-depth.md#light-through-fog).
